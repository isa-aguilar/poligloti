# Demo learner

An invented learner, **Alex**, who studies English at B1 and has three weeks of invented progress: an initial assessment, a few sessions, vocabulary, a weekly focus and a score history, so every screen has something to show.

Load it into your data folder (it never overwrites an existing learner):

```bash
python -m scripts.load_demo
```

With Docker: `docker compose run --rm poligloti python -m scripts.load_demo`.

Everything here is fictional. Delete the `alex/` folder in your data directory to remove it.
